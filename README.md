# PAW FrontOffice

Angular frontend for a supermarket marketplace developed as an academic web development project.

## Features

- User authentication
- Product catalogue
- Shopping cart
- Checkout flow
- Order management
- Product reviews
- Price comparison
- Integration with the PAW REST API

## Tech Stack

- Angular
- TypeScript
- HTML
- CSS
- Bootstrap
- REST API
